# Address_Book
# UC2 – Address Book CRUD Operations with MySQL

### What I Did
- Connected the Spring Boot application with MySQL.
- Created the Contact entity with fields like ID, name, phone number, email and address.
- Created a Contact Repository using JpaRepository.
- Implemented CRUD REST APIs:
    - POST – Add a contact.
    - GET – Retrieve all contacts.
    - GET by ID – Retrieve a specific contact.
    - PUT – Update contact details.
    - DELETE – Delete a contact.
- Tested the APIs using Postman.

### Use of It
- Stores contact details permanently in a MySQL database.
- Allows users to add, view, update and delete contacts.
- Spring Data JPA reduces the need to write SQL queries manually.
- Makes contact management easier through REST APIs.
