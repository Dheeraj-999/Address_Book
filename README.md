# Address_Book
# UC3 – DTO and Service Layer

### What I Did
- Created a ContactDTO class to transfer contact data.
- Created a ContactService class to handle business logic.
- Moved contact-related operations from the controller to the service layer.
- Used constructor-based dependency injection.
- Updated the controller to communicate with the service layer.
- Tested the APIs using Postman.

### Use of It
- Separates business logic from API handling.
- Keeps the controller simple and clean.
- DTO helps control what data is transferred between client and application.
- Makes the application easier to maintain, test and extend.
