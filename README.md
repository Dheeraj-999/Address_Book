# Address_Book
# UC4 – In-Memory List Storage

## What I Did
- Implemented in-memory contact storage using Java `ArrayList`.
- Added functionality to add, view, update, and delete contacts.
- Implemented automatic ID generation for contacts.
- Updated the Service Layer to manage contacts without MySQL.

## What I Learned
- How to use Java Collections (`ArrayList`).
- How to perform CRUD operations on in-memory data.
- How to manage temporary data storage.

## Note
Contact data is stored temporarily and is lost when the application restarts.

## Technologies Used
Java 21, Spring Boot, REST API, ArrayList, Maven.
